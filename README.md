主要功能如下：

- **价格走势**：收录 2006年11月1日至 2026年11月19日共 5,050 个伦敦交易日的上午定盘，单位原序列为美元/金衡盎司。顶部会显示最新定价、区间最高、区间最低，以及这二十年间的涨跌幅。
- **时间范围**：下拉框可选最近一年、五年、十年或二十年；也可以拖动底部滑块，或在图内滚动滚轮缩放、拖动平移。纵轴会随当前窗口自动调整。
- **货币切换**：可在美元、人民币/克、欧元、英镑、日元之间切换。人民币按历史汇率折算后再除以 31.1034768 克，显示为元/克；其余货币仍按每盎司计价。图表、指标和提示框会同步更新。
- **事件标注**：图上标有 160 条影响金价的事件，按类型配色，按影响大小分三级（圆点越大、字号越大）。类型包括货币政策（含美联储与欧央行每次加息、降息）、地缘政治、金融危机、通胀经济、央行购金、美元汇率和公共卫生。点击上方标签可显示或隐藏某一类。
- **悬停与点击**：鼠标在折线上移动时，会出现跟随的虚线十字准星，并显示当日价格，以及前后约两周内最多 4 条相关事件的简介。点击事件圆点也会弹出同样的提示框。非交易日事件会注明所取的邻近定价日。
- **数据来源**：金价来自 321gold、SD Bullion、Westmetall，并与世界黄金协会等公开记录交叉核对；人民币汇率主要来自美联储 H.10，其余汇率来自欧洲央行参考汇率。每条事件都附有来源链接。页面更新日期为 2026年11月20日（亚洲/上海时区），不是实时行情。
